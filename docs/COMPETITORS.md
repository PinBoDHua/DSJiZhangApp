# 同类产品对标 · 2026-11

> 目的：0.7.0「轻小美」不是凭感觉做视觉，而是拆解同类最佳产品已经验证过的体验，找到薪时可以赢的地方。
>
> 结论：**不在功能数量上竞争，在「打开快、记一笔快、看着舒服、装得小」上竞争。**

---

## 1. 横向对比

| 产品 | 定位 | 记录速度 | 强项 | 短板 / 用户反馈 | 薪时的选择 |
| --- | --- | --- | --- | --- | --- |
| [记工宝](https://apps.apple.com/cn/app/id6503635614) | 打工人记工算薪 | 「三步完成一条记录」 | 多工种、日历、多账本、请假、Excel、云端同步 | 账号 + 云端，功能入口多，信息密度高 | 保留多岗位 / 多计薪；删除账号与云端；首屏只留高频 |
| [安心记加班](https://apps.apple.com/cn/app/id1148517227) | 加班 / 工时记录 | 快速记加班、批量记 | 三种计薪模式、批量、老牌用户量 | 安卓包约 92MB；广告与工厂点评；评论里有「每次都要选几个小时很鸡肋」 | 单机 3.3MB；无广告；默认班次 + 时长快选 |
| 极简工时 | 小时工记账 | 打卡 + 补记 | 自定义工时、补贴扣款、Excel、桌面小组件、暗黑 | 功能入口偏多 | 暗黑 / Excel 保留；小组件排后续 |
| 小时工记账 | 小时工 / 临时工 | 「5 秒速记」 | 无需登录、离线、日历、备注 | 视觉与信息层级普通 | 3 步记一笔 + 更好的排版 |
| [鲨鱼记账](https://www.xiledong.com/news/1465.html) | 极简记账 | 「3 秒记一笔」 | 无二级分类、智能备注、轻量视觉 | 不是记工场景 | 学「少做选择」：默认岗位 / 班次 / 今天 |
| [Toggl Track](https://www.capterra.com/p/247745/Toggl/reviews/) | 专业计时 | 开始 / 停止最直接 | 报表与项目维度成熟 | 桌面启动慢（用户反馈约 5 秒）、偏团队 | 计时保留；首页打开即用，不做项目管理 |

### 用户反复提到的痛点

- 「记一笔要点太多东西」——分类、时长、加班、备注层层展开。
- 「每次都要选几个小时」——没有默认班次 / 常用时长。
- 「不好看，坚持不下去」——工具感太重，缺少日常陪伴感。
- 「广告太多」「包太大」——离线工具被做成流量产品。
- 「换手机数据没了」——0.6.0 已用搬家包 / 自动备份解决。

## 2. 我们保留的

- 三种计薪 + 计件、加班倍率、月薪封顶、超休、借支、结算锁定。
- 日历 / 考勤 / 排班 / 批量补记。
- 工资条、二维码、PDF、Excel、CSV。
- 本机时光机、加密搬家包、自动备份、账本体检。
- 无账号、无网络权限、无广告、无统计 SDK。

## 3. 0.7.0 改掉的

| 问题 | 0.7.0 的做法 |
| --- | --- |
| 首屏信息多 | 首页只保留「本月 + 今天 + 最近」；计划 / 统计下移 |
| 记一笔要滚动 | 默认岗位 / 班次 / 日期；常用时长 4–12h 一键；底部固定预览 |
| 首页没有「复用上一班」 | 今天没记工时，显示「照上次班次」 |
| 视觉偏后台系统 | 大数字、少边框、多留白；悬浮底部导航；暖纸色 + 深松绿 |
| 首屏 JS 大 | 路由懒加载：首页 / 记一笔先加载，其余页面按需 |
| 安装包大 | R8 + 资源压缩；去掉未使用的 html2canvas；APK 5.31MB → 3.30MB |
| 图标偏旧 | 更干净的渐变表盘 + 琥珀印章；同步启动屏 |

## 4. 不做

- 不做社区 / 工厂点评 / 招聘（安心记加班的路线）。
- 不做账号 / 云同步（0.6.0 已暂停）。
- 不做广告 / 统计 SDK / 社交裂变。
- 不为了「功能看起来多」增加低频入口。
