## 1. 为什么不是「云同步优先」

v0.3 原路线里写了「账号与云同步」。真正开始设计时遇到三个硬条件：

1. 需要一套可托管的账号/同步服务，不能只靠静态 PWA。
2. 工资数据敏感，账号、加密、找回、注销、备份都要一起设计。
3. 目标用户是小时工/日结工，注册和服务器运维成本越高，越容易退回纸笔。

所以这一版先把**不依赖服务器、立刻可用**的能力做扎实；云同步单独设计、单独实现，而不是在本地账本里塞一个假登录入口。

## 2. 计件工资

### 2.1 工作设置

- 计薪方式新增 **计件**。
- 设置「每件单价」和「计件单位」（件 / 米 / 平方 / 单…）。
- 计件工作不显示标准工时和加班费设置；工资只按数量 × 单价。
- 结算周期仍可选日结 / 周结 / 月结。

### 2.2 记一笔

- 表单显示大号「计件数量」输入，实时计算 `数量 × 单价`。
- 工时改为**选填**，只进入统计，不参与计件工资。
- 奖金 / 扣款 / 备注照常可用。
- 计件工作不参与计时：首页计时入口会排除计件岗位；如果只有计件工作，不显示计时按钮。

### 2.3 计薪与结算

- 每条计件工记金额 = `数量 × 记录时单价 + 奖金 − 扣款`。
- 单价、单位随工记快照保存，之后改单价不影响历史金额。
- 结算快照新增 `payType / quantity / unitLabel`，结算单展示：
  - 数量、工时、出勤；
  - 计件工资 = 总数量 × 对应单价；
  - 每笔数量与金额明细。
- 计件不计算加班费；工时只做统计。
- 月度封顶只适用于月薪，不套用到计件。

### 2.4 边界

- 一份工作只维护一个计件单位；同一结算周期内混用「件 / 米」等不同单位，不做自动换算。
- 不支持阶梯计件、团队计件、按工序拆分。
- 数量允许小数（如 12.5 米），按 0.01 精度保存。

## 3. PDF 对账单

- 已结算单的工资条弹层新增 **PDF** 按钮。
- 复用现有 1080×1440 工资条 PNG，嵌入单页 PDF：
  - 保留中文、品牌版式、金额明细和结算章；
  - 不需要在 PDF 里另嵌中文字体；
  - 下载文件名与工资条一致，扩展名 `.pdf`。
- jsPDF 使用动态 import，只有点 PDF 时才加载，不拖慢首页。
- 文件完全在浏览器生成，不上传服务器。

## 4. 加密备份

### 4.1 导出

- 「我的 → 数据 → 导出加密备份」。
- 设置密码（至少 6 位）并二次确认。
- 客户端使用：
  - **PBKDF2-SHA256**，250,000 次迭代；
  - 16 字节随机 salt；
  - **AES-256-GCM**，12 字节随机 IV；
  - 输出带版本、算法、salt、iv、密文的 JSON。
- 密码不写入文件、不写入 localStorage、不上传。
- 加密文件中不出现称呼、工作名、金额等明文。
- 忘记密码无法恢复，界面明确提示。

### 4.2 导入

- 导入时自动识别普通 / 加密备份。
- 加密备份先弹出密码框，解密成功后才进入「覆盖当前数据」确认。
- 密码错误或密文被篡改时拒绝导入，并提示「密码错误，或备份文件已损坏」。
- 普通 v1 / v2 / v3 备份继续兼容。

## 5. 备份提醒

- 每次成功导出普通或加密备份，记录本机 `xinshi.lastBackup` 时间。
- 「我的 → 数据」显示上次备份日期。
- 首页在以下情况显示琥珀提示条：
  - 有工记；
  - 从未备份且账本已使用 ≥ 7 天，或距上次备份 ≥ 14 天。
- 点击提示条进入「我的」，自行导出；不自动上传、不弹强制窗。
- 清空数据时一并清除备份时间。

## 6. 数据模型 v3

```ts
type PayType = 'hourly' | 'daily' | 'monthly' | 'piece';

interface PayRule {
  payType: PayType;
  rate: number;
  unitLabel: string; // 计件单位，其他类型固定存默认值
  // ...
}

interface Entry {
  quantity: number; // 计件数量；非计件为 0
  // ...
}

interface Settlement {
  payType?: PayType;
  quantity?: number;
  unitLabel?: string;
  // ...
}
```

- 存储键升级为 `xinshi.state.v3`。
- 启动时依次尝试 v3 → v2 → v1；读旧数据后补默认值并写回 v3。
- 旧工记缺 `quantity` 补 0；旧规则缺 `unitLabel` 补 `件`。
- 旧结算没有计件字段时保持 `undefined`，不按当前工作规则猜测，避免历史结算被误标为计件。
- 导出包 `version: 3`；仍接受 v1 / v2 备份导入。
- 计时器如果指向计件工作（旧数据或异常导入），自动丢弃。

## 9. 已知限制

- **计件**：一岗一单位；不支持阶梯价、工序价、团队计件；计件不计加班。
- **PDF**：单页图片型 PDF，文字不可选中；无企业抬头 / 自定义模板。
- **加密**：密码丢失无法找回；加密强度依赖浏览器 Web Crypto；没有密钥托管。
- **备份提醒**：只记录本机导出时间，不跨设备；导入旧备份不会刷新提醒。
- **云同步 / 账号 / 可靠后台通知**：本版未实现，见 [CLOUD-SYNC.md](CLOUD-SYNC.md)。
- **Android**：MediaStore 直接保存需要 Android 10+；低版本可安装但导出会提示使用分享方式（当前未实现）。测试包为本机签名，未上架应用商店；debug / release 签名不同，切换需卸载。
