# 薪时 v0.4.2 · 顺手版

> 版本：0.4.2 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 不新增业务模型，只把每天都会碰到的动作做顺：看清月休额度、少填一笔、别误丢输入。

---

## 1. 这次解决的摩擦

### 1.1 首页月休额度

固定月薪 3500、月休 5 天时，首页原来只显示「休 2 天」，看不出还剩多少。

现在首页直接显示：

`2026年11月 · 已记 2 天 · 休 2/5 天`

- 只有一个固定月薪岗位时，显示该岗位的已休 / 额度；
- 多个固定月薪岗位时退回显示总休息天数，避免把不同岗位额度相加误导；
- 休息弹层仍显示「本月已休 2 / 5 天 · 剩余 3 天」。

### 1.2 复制到今天

工记详情新增「复制」：

- 只复制岗位、日期以外的班次 / 工时 / 数量 / 规则 / 备注；
- 不复制奖金、扣款、节假日标记，避免重复发钱；
- 复制到**今天**；如果今天该岗位有休息标记，会自动移除休息；
- 当天合计超过 24h、或今天所在周期已结算，会拒绝并提示；
- 按钮在今天的工记详情里隐藏，避免同一天重复复制。

### 1.3 关闭前提醒

- 记一笔 / 编辑工记时，只要动过表单（输入、选工作、换日期、切换模式等），点关闭 / 按返回键 / 点遮罩都会先问「放弃这次编辑？」；
- 选择「继续编辑」保留内容；选择「放弃」才关闭；
- 没动过表单则直接关闭，不打扰；
- 保存成功后正常关闭，不弹提醒。

---

## 2. 不改什么

- 不改变计薪、结算、休息日、固定月薪的规则；
- 不改变存储 schema，仍是 v4；旧数据不需要迁移；
- 不改变 Web / APK 的数据格式；
- 复制工记不会自动打开编辑表单，避免打断连续记录。

## 4. 已知限制

- 复制只到「今天」，不支持复制到任意日期或批量复制。
- 复制不包含奖金 / 扣款；需要的话复制后去记录里编辑。
- 关闭提醒只覆盖记工表单，不覆盖工作设置页。
- 月休额度只是提示，不会自动扣固定月薪。
