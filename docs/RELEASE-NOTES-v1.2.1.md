# 薪时 v1.2.1 复审修复说明

> 版本：**1.2.1** ｜ versionCode：**1201** ｜ 发布日期：**2026-11-07**
>
> 主题：**复审收口 · 不加功能，只把账和对账路径修稳**
>
> 一句话：在 v1.2.0 基础上对 1.1 / 1.2 新增的前后端代码做了一轮复审，修掉会造成错账、数据丢失、
> 误判加密和卡死真机的 20 类问题；数据格式仍是 **schema v7**，覆盖安装、旧备份 / 搬家包 / 快照继续可用。

---

## 1. 本版定位

v1.2.0 已发布且出过签名包，因此这次复审修复按补丁版 **1.2.1** 发布，不改变任何功能口径：

- 不加新页面、不改数据格式、不做迁移；
- 只修「会算错钱 / 会丢数据 / 会误报成功 / 会卡住」的问题；
- 修复后重新跑了单测、浏览器场景、响应式矩阵和 Redmi 真机 12 步验收。

---

## 2. 修复清单

### 2.1 计薪与统计

- **月薪同日去重口径统一**：普通汇总、记录页单日小计、12 周热力图也按「同工作同日只计一次月薪基础工资」，
  与月薪封顶、首页月合计一致；此前周统计 / 今日卡会比月统计多算一份日折算。
- **月薪图表取整**：按出勤日分摊时，逐日舍入余数归到最后一天，图表之和与上方合计精确一致（此前差 1–2 分）。
- **固定月薪结算文案**：只有「整自然月 + 规则一致」时才写「整月发放、不按出勤扣减」；周结 / 日结或同月调价时
  改为「按本期实际出勤折算」，与实际金额一致。
- **快照 / 搬家包清单**：「工记合计」改用与首页一致的月薪封顶口径。
- **预算文案**：收入提示从「已完成」改为「已计入」，避免固定月薪在月初就显示「已完成」。

### 2.2 周期记工

- **回溯上限**：首次补记或长时间未打开后，只回溯最近 **120 天**；更早的规则日不再补，页面明确提示。
  修复一次生成上千条工记（实测 2499 条）把真机卡住的问题。
- **归档工作的规则**：工作归档后仍可关闭 / 编辑其周期规则；此前开关永远保存失败，自动补记变成关不掉的后台行为。
- **输入校验**：补齐重复频率、每月日期、工作日范围的校验。
- **跨天**：App 挂在后台跨天再回来时刷新「今天」，并按自然日重新执行自动补记。

### 2.3 备份、导入与恢复

- **搬家包自洽**：清单改为按「导入时同一套规范化规则」重算，修复 `standardHours < 0.5` 等被规范化后
  App 自己导出的包被判「清单与内容不一致」的问题。
- **全空白密码**：搬家包密码全是空格时直接拒绝，不再静默导出明文包却显示「已加密」；两次输入按去首尾空格后比较。
- **恢复页导出**：损坏账本页的「导出原始账本」改走原生 `SaveFile`，并显示保存路径 / 失败原因；
  此前 Android WebView 里 `<a download>` 静默不落盘，最关键的救援动作是失效的。
- **取消竞态**：覆盖导入 / 撤销结算在等待快照期间先关闭确认框并加互斥，避免「点了取消、覆盖却继续执行」；
  加密备份在密码框取消后，迟到的解密结果不再弹出导入确认。
- **自动备份**：清理旧文件失败不再把本次备份误报为失败，只提示清理失败，下次继续清理。

### 2.4 原生壳

- **同名文件保存**：改为「先以最终文件名发布，再清理同名旧文件」；被系统自动改名时再改回原文件名；
  发布失败只删临时文件，旧备份不受影响。此前先删旧文件，发布失败会丢掉旧备份并留下隐藏 `.tmp`。
- **安全区脚本**：`onPageStarted` 时新文档的 `documentElement` 可能还没建好，脚本加了 DOM 兜底，
  真机每次加载不再抛一次 `Cannot read properties of null`。
- **诊断日志**：读取改为循环读满，避免大日志只读一部分。

### 2.5 交互与可访问性

- **嵌套弹层滚动锁**：抽屉 + 确认框同时关闭后 `document.body.style.overflow` 不再卡在 `hidden`，
  删除工记、放弃编辑后页面可继续滚动。
- **状态引用**：`restoreEntry` 的「已在账本里」分支补走统一 `commit`，不再绕过 v1.2 的状态引用同步。
- **照片失败提示**：编辑旧工记时新照片写入失败会保留原照片并如实提示；新工记失败则撤掉未兑现的引用。
- **提示文案**：删除周期规则、复制工记到今天、删除工作的条件说明都按真实原因显示。
- **ARIA**：预算进度条补 `role="progressbar"` / `aria-valuenow`，工记工具组与筛选组补 `role="group"`；
  记录页视图切换按钮不再长期显示为选中。
- **深色预算卡**：修复 `.card` 深色边框把预算分档边框覆盖的问题，并补齐 `is-info` 等缺失样式。
- **CSV**：单元格补上 `\r` 转义，避免备注里的回车破坏行结构。

## 3. 兼容与升级

- 覆盖安装：同签名可直接覆盖 v1.2.0 / v1.1.0，账本保留。
- 数据格式：仍是 `xinshi.state.v7`，无字段变更；旧备份、搬家包、本机快照继续可导入。
- 已生成结算单是锁定快照，本版不改历史结算。
- **金额可能变化**：同一工作同一天有多笔月薪工记时，周统计 / 单日小计 / 热力图会按去重口径显示，
  未结金额与 v1.2.0 略有差异（月统计本身不变）。

## 6. 已知边界

- 同月多次修改月薪合同只能按每日快照做近似折算；严格入职 / 离职 / 调薪区间请另建工作或在结算时核对额外奖扣。
- 固定月薪在周结 / 日结下按周期出勤折算、周期级封顶，与月度整月封顶之间是近似。
- 预算进度沿用「本月预计收入」口径：固定月薪当月有工记即计入整月金额，不是按天累计的已赚金额。
- 周期规则首次补记最多回溯 120 天；不会在系统后台生成，只有打开 App 才补记。
- 完整 CSV 是对账导出，不是可导入的备份格式。
- Android 9 及以下的原生公共下载保存仍受系统能力限制，界面会返回明确错误。
