## 2. 逻辑与数据修复

### 2.1 账本引用与回收站

- **恢复借支补结算守卫**：回收站恢复借支时校验 `settlementId`，与工记恢复同口径。此前导入含「已结算借支」
  的备份再恢复，会留下单向引用，下次启动整本账被判损坏而锁死。
- **回收站限量边界**：`pushTrash` 在 cap=0 时返回空列表，修复负数 slice 的潜在越界。

### 2.2 备份与搬家

- **fnv1a 搬家包跨环境校验**：旧 WebView（无 SHA-256）导出的 fnv1a 校验包，在新设备上按原算法验证，
  不再报「当前环境无法验证」，打通旧→新换机这条搬家包最核心的路径。
- **解密错误归因**：密码正确但账本结构损坏时，原样上抛结构错误（如「备份缺少工作或工记数据」），
  不再一律误报「密码错误，或备份文件已损坏」让用户反复试密码。

### 2.3 计薪与对账

- **超休额度按周期折算**：固定月薪在非整月周期（导入数据可能出现）结算时，月休额度按周期占当月比例折算，
  不再每个短周期重置一整月额度而系统性少扣超休；整自然月口径不变（比例恰为 1）。
- **Excel 对账口径**：「已收 / 待收 / 收款状态」改用与 CSV / 工资条一致的 payment 口径（夹取到 [0, 净额]），
  杜绝负待收；收款状态在未显式标记时按已收金额推断。
- **健康检查误报**：不再把合法的负净额（借支超过应发）判为「严重」，只保留周期颠倒与非有限金额检查。

### 2.4 持久化与快照

- **存储不足误报**：`saveState` 先单独兜底写主题，账本写入才是关键路径；主题写失败不再误报
  「本地存储空间不足」让用户以为账本没存上。
- **跨午夜每日快照**：应用长期挂着、记录数不变时，靠 visibilitychange + 周期复查补拍每日快照，
  不再整天漏拍。

## 3. UI/UX 修复（沿现有视觉）

- **暗色对比**：选中态（周几 / 计划日 / 时长 / 已排班 / 批量勾选）统一深绿底 + 浅字；分类统计色板改由
  设计 token 派生并给暗色提亮变体；`--muted-2` 提对比到 AA。
- **焦点与键盘**：焦点管理不再抢走输入框 `autoFocus`（键盘弹起又收回）；提示条跟随软键盘上移。
- **误弹放弃编辑**：记一笔表单去掉「任意点击即脏标记」，未真正编辑时关闭不再弹「放弃这次编辑?」。
- **表单错误可访问**：错误条加 `role="alert"`，并随用户编辑即时清除，不再留陈旧红条。
- **读屏名称**：记一笔抽屉按「记一笔 / 编辑工记」命名，不再统一读作「编辑」。
- **文本与表头**：工记元信息长时段 / 加班改省略号收尾不再硬裁切；考勤表体成为滚动容器使表头真正吸顶。
- **点击区**：小控件（时长 / 周几 / 色板 / 周标签 / 计时取消 / 搜索清除）扩大不可见点击区，不改视觉尺寸。
- **照片与工资条**：照片全屏阻断滚动穿透、保存加防重复；工资条页脚备注防抖重绘、保存加防重复。
