# 薪时 v0.4 · 固定月薪，也能随机休

> 版本：0.4.0 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 这版来自一个真实场景：**月薪 3500，休息随机，每月约 4–5 天，每天 6 小时、午休 2 小时。**
> 原来的「月薪按 22 天出勤折算」会把随机休息算成缺勤；v0.4 增加固定月薪、月休额度和班次模板。

---

## 1. 用户例子

- 月薪：3500 元，月结。
- 休息：不固定，每月大约 4–5 天。
- 班次：每天在岗 6 小时，午休 2 小时（例如 09:00–17:00，休息 120 分钟）。

旧版本的问题：

1. 月薪 3500 ÷ 22 天，休息 4–5 天后出勤只有 17–18 天，结算会低于 3500。
2. 每天 6 小时、午休 2 小时需要每次手填，容易记成 8 小时。
3. 随机休息没有留痕，月底不知道自己休了几天、还剩几天额度。

---

## 2. 固定月薪

`PayRule` 新增：

```ts
monthlyMode: 'prorated' | 'fixed'
restDaysPerMonth: number
```

- **按出勤折算**：沿用旧算法，按 `月薪 / 计薪天数 × 出勤天数`，超过整月封顶。
- **固定月薪**：整月基础工资 = 月薪本身，不按出勤天数打折；休息日不会自动扣钱。
- 固定月薪仍保留工记的日折算展示（方便看单日参考），但结算基础以固定月薪为准。
- 加班费、奖金、扣款、借支仍可叠加；固定月薪不改变这些规则。
- 月中入职 / 离职、超出月休额度的缺勤，建议在结算「额外奖扣」里调整（本版不自动判定）。

### 结算展示

- 固定月薪结算单显示：`固定月薪`、`出勤 X 天 / 休息 Y 天 / 工时 Z h`。
- 明细中的单笔金额标注「折算」，并说明「固定月薪整月发放，不按出勤天数扣减」。
- 工资条 / PDF 同样显示「固定月薪」和休息天数。

---

## 3. 月休额度与休息日

- 工作设置新增「月休额度」（仅固定月薪），默认 5 天。
- 新增 `RestDay` 数据：`jobId + date + note`。
- 入口：
  - 首页「休息」按钮（咖啡杯）；
  - 记录页顶部「休息」；
  - 日历选中日期下方「标为休息」。
- 休息日会：
  - 在日历显示「休」标记；
  - 出现在记录页月度摘要「本月另休 X 天」；
  - 在休息弹层显示「本月已休 X / 额度 Y 天，剩余 Z 天」；
  - 进入固定月薪结算的休息天数统计。
- 约束：
  - 同一天同一岗位不能既记工又标休息；
  - 已结算周期不能补标 / 取消休息；
  - 记工时会自动移除同岗位同日的休息标记。
- 休息日**不自动扣薪**；额度只是统计和提示，不替用户做惩罚判断。

---

## 4. 班次模板

`Job` 新增：

```ts
shift: {
  startTime: string;
  endTime: string;
  breakMinutes: number;
}
```

- 工作设置新增「默认班次」：上班、下班、午休分钟，实时显示在岗小时。
- 一键预设：
  - **6h + 午休 2h**：09:00–17:00，休息 120 分钟，标准工时 6h；
  - **标准 8h**：08:00–17:00，休息 60 分钟，标准工时 8h。
- 新建工记自动带入该班次；仍可单次修改。
- 固定月薪工记会把班次净工时（6h）作为默认统计工时，午休 2h 只影响工时，不影响固定月薪。
- 时薪 / 日薪 / 计件同样可使用班次模板。

## 5. 数据模型 v4

- `PayRule` 新增 `monthlyMode`、`restDaysPerMonth`。
- `Job` 新增 `shift`。
- `AppState` 新增 `restDays`。
- `Settlement` / `SettlementDraft` 新增 `monthlyMode`、`restDays`。
- 存储键升级 `xinshi.state.v4`；v3 / v2 / v1 自动迁移。
- 旧月薪默认 `monthlyMode='prorated'`，不改变历史行为。
- 旧工作补默认班次 08:00–17:00 / 60 分；旧休息日为空。
- 导出包 `version: 4`；仍接受 v1 / v2 / v3 备份导入。

## 7. 已知限制

- **固定月薪假设整月在职**：月中入职 / 离职、超出月休额度的缺勤不自动折算，需在结算「额外奖扣」处理。
- **月休额度只做提示**：不自动扣薪，不做请假审批。
- **休息日与工记互斥**：同一岗位同一天二者只能有一个。
- **班次模板是默认值**：实际工时可在单笔记工中修改；不处理排班表 / 轮班。
- **固定月薪的日折算**仍使用「参考计薪天数」，仅作展示。
- 云同步、账号仍未实现，见 [CLOUD-SYNC.md](CLOUD-SYNC.md)。
