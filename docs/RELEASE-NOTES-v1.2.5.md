## 2. 数据与账本一致性

- **结算单不再被跨标签页事件吞掉（P1）**：结算提交统一走持久化守卫 commit()。
- **跨标签页并发写入改为乐观合并（P1）**：落盘前比对远端原文，冲突时重读远端并重放本窗口更新，
  两个窗口的新增记录不再互相整包覆盖；清空/导入/恢复快照会广播整包替换意图，防止旧账被写回。
- 导入备份增加 20MB 上限、字段钳制与结构校验（工时/加班/费率/奖扣/时间戳/照片引用/跨集合 ID 等）；
  「已结算周期内未锁定工记」在导入时明确拒绝并给出体检规则。
- 启动清理孤儿照片时跳过启动后新拍的照片，避免误删不可再生的照片。
- 快照完整性升级为 SHA-256 + 字节数校验，解压输出上限 64MB；旧格式快照可读并标记 legacy。

## 3. 计薪与结算

- **月薪 × 非月结周期封顶修正（P1）**：按「周期占当月天数」折算封顶，
  月薪 3500 / 计薪 22 天、2026-11 全勤的周结合计由 4772.74 降为 3500.02（分币舍入），月结保持 3500。
- **超休额度不再同月重复扣（P1）**：非整月周期只展示折算额度、不自动扣款；
  月休 5 天分三周休的误扣 264.10 归零，整月周期口径不变。
- 超休扣款改为先乘后舍入；结算校验码升级为 SHA-256 短码并覆盖全部分项与收款字段（旧码仍可核验）。
- 记录页/日历/统计页统一「封顶后按日分摊」口径；Excel 未结预估行按岗位×周期逐期汇总；
  CSV 数字统一两位小数；净额≤0 的结算单可标记「无需收款/已结清」。

## 4. Android 隐私与发布链

- 崩溃诊断只写应用私有目录，正式包不再写公共 Download，并清理历史残留；隐私政策补充披露。
- 新增 dataExtractionRules：云备份与换机迁移排除全部应用数据域（配合 allowBackup=false 双保险）。
- Gradle 守卫拒绝「release 签名 + debuggable」产物；check:release 增加产物 debuggable / 政策死链 /
  占位邮箱 / FileProvider 白名单 / CSP / SW 版本等断言。
- 隐私政策：删除 404 在线版本链接，支持邮箱改为真实可收信地址，政策版本 2026-11-17。
- 诊断日志增加大小上限与堆栈截断；LMK 回收不再按崩溃计数；崩溃页增加重启/退出并可拦截返回键。
- SaveFile 插件卫生：分享缓存清理、ClipData、prune LIKE 转义；清理陈旧中间产物与模板测试文件。

## 5. PWA 与前端体验

- **PWA 首装离线可用（P2）**：构建期生成预缓存清单（SW v32），所有路由 chunk 与入口资源安装即缓存。
- 构建期注入 CSP（内联主题脚本 SHA-256，动态计算），dev 不注入。
- 页级错误边界：单页渲染异常只坏当前页并可返回；preloadError 兜底增加内存节流。
- 隐藏金额覆盖首页单价/计时弹层；工资条/QR/分享入口在隐藏模式下提示「导出内容仍含明文」。
- 记录页/日历/统计金额口径统一；岗位卡「已结算待收」纳入徽章；复制到今天改用岗位当前单价。
- 可访问性与触控：--muted-2 对比度达 AA、危险操作触控目标 44px、Toast 连点与确认框焦点修复。

## 6. 兼容与升级提示

- 数据格式仍为 schema v7，覆盖安装不迁移、不丢数据。
- 隐私政策版本升到 2026-11-17：升级后首次打开会重新弹出隐私同意。
- Service Worker 缓存版本 v32：已打开的旧页面会提示刷新/自动更新。
- 旧版 App 无法校验新版搬家包（checksumVersion=2 单向兼容），建议两端同版本后再跨版本搬家。
