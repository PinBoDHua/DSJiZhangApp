# 薪时 v0.8.0 · 「找得到 · 看得远」全面打磨

> 版本：0.8.0 ｜ 日期：2026-11-06 ｜ 状态：**已实现并通过验收**
>
> 一句话：**功能不再加数量，把「回看、查找、稳定、顺手」做到位，为 1.0 打底。**

> 基线：v0.7.2（APK 3.15MB / 首屏 JS 129KB gzip / 134 单测 / 94 浏览器场景 / 分辨率矩阵 105+12 全绿）。

## 1. 为什么是 0.8.0

v0.7.2 已经解决了「能不能用、装得上、闪不闪退、屏宽不屏宽」。这一版不再开新的产品方向
（工头台账需要新的数据模型和交互，仍留在 0.9/1.0 评估），而是把已有账本做三件更基本的事：

1. **找得到**：账本记了几个月以后，翻月份找一笔工记越来越累，缺一个真正的搜索。
2. **看得远**：统计只有本周 / 本月，看不到一整年的收入、工时和岗位分布。
3. **更稳更快**：错误边界、版本号对齐、标题换行、触控尺寸、深色对比、首屏拆包与预取。

它是一次「打磨 + 补齐」的版本：不改计薪公式、不动数据格式、不引入权限 / 网络 / 账号，
旧备份与旧数据继续可用。

## 3. P0 范围

### P0-1 记录搜索

- 记录页右上角新增搜索入口，进入独立的搜索页（懒加载）。
- 搜索范围：全部工记（含已结算），不限于当前月份。
- 匹配字段：
  - 岗位名称、雇主名称；
  - 工记备注；
  - 日期：`2026-11-06` / `2026.11.06` / `2026/11/06` / `11-06` / `11月6日` / `2026年11月`；
  - 金额：工记合计的整数 / 两位小数，例如 `159`、`159.09`。
- 多个关键词按空格拆分，**全部命中**才显示（AND）。
- 结果按日期倒序；显示命中数量、合计金额、合计工时；按日分组，点开可进详情。
- 岗位筛选 chips；输入框自动聚焦，提供清空按钮；空查询给出示例提示，无结果给出可执行建议。
- 纯函数放在 `src/lib/search.ts`，单测覆盖日期 / 金额 / 备注 / 多词 / 空结果。

### P0-2 年度统计

- 统计页周期切换增加「本年」，与「本周 / 本月」并列。
- 年度范围取自然年，可向往年翻页，不能翻到未来。
- 年度数据口径：
  - 收入、加班、奖金、扣款：按 `sumEntriesCapped` 汇总；月薪岗位**按岗位 × 月**分别封顶，年合计 = 12 个月封顶值之和；
  - 出勤天数按自然日去重；工时 / 加班工时累加；
  - 12 个月柱状图：每月收入 = 该月 `sumEntriesCapped` 合计（与账本口径一致，不用单日折算）；
  - 岗位分布：每个岗位按月封顶后跨月累加。
- 无数据时仍显示年度空状态，不展示无意义图表。
- 纯函数放在 `src/lib/yearStats.ts`，单测覆盖固定月薪封顶、普通月薪封顶、时薪 / 日薪、跨岗位、空数据。

### P0-3 稳定与打磨

- **版本集中化**：`vite.config.ts` 从 `package.json` 注入 `__APP_VERSION__`；引导页、关于页、页脚、搬家包 `appVersion` 统一引用；Android `build.gradle` 默认 `800 / 0.8.0`。
- **错误边界**：根级 `ErrorBoundary`，出现渲染异常时展示「账本还在，页面出错了」+ 重新加载 / 返回首页，不白屏；错误写入控制台。
- **记录页头部**：标题禁止换行；动作按钮在 320–430px 收成图标 + 无障碍名称，≥431px 显示文字。
- **触控目标**：图标按钮、开关、搜索清空等主要控件 ≥ 44px（文字 chips 保持紧凑但增加内边距）。
- **深色模式**：逐页截图检查正文 / 次要文字 / 图表对比度，修正发灰或看不清的样式。
- **动效与焦点**：`prefers-reduced-motion` 下关闭页面 / 抽屉动画；搜索页输入框有可见焦点；Esc / 安卓返回键行为一致。
- **离线缓存**：Service Worker 缓存版本递增到 v22，避免升级后旧壳残留。

### P0-4 性能

- 首屏主包不增重；搜索页 / 年度统计复用现有懒加载与图标。
- 首屏绘制完成后 `requestIdleCallback` 预取记录 / 结算 / 统计 / 我的等路由 chunk，底部导航切换不再先出骨架。
- 对首页 / 记录 / 统计的高频派生计算做 `useMemo`，减少无关 state 变化的重算。
- 构建后记录主 JS、CSS、APK 体积对比；真机记录冷启动 `am start -W`。

### P0-5 真机与发布

- Playwright 全量回归 + 响应式矩阵 + 深色 / 搜索 / 年度新场景。
- Android debug 包通过 `adb forward` + CDP 跑真机交互：搜索、年度、记一笔、返回键、深色、键盘。
- 签名 release 包安装到 Redmi Note 13 Pro 5G（Android 16）：
  - `am start -W` 冷启动；
  - `logcat` 无 `FATAL EXCEPTION` / 未捕获 `pageerror`；
  - 首页 / 记录 / 搜索 / 年度 / 结算 / 数据与安全截图；
  - 权限仍只有通知 / 开机提醒 / WakeLock，无 INTERNET。
- 产出：`release/xinshi-v0.8.0.apk`、`.aab`、`shots/v0.8/`、`shots/android-v080/`、`test-results-v080*`。

## 4. 不做 / 明确留到后面

- **工头台账**（多人档案、按人分账）：需要新的数据模型与权限边界，不在本版硬塞；继续留在 0.9/1.0 评估。

- **云同步 / 账号 / 广告 / 统计 SDK**：继续暂停，不引入网络权限。
- **数据格式**：仍是 schema v7；本版不新增字段，旧备份 / 搬家包 / 快照完全兼容。

### 6.4 差异与未做

1. **工头台账 / 多人分账**：需要新的数据模型和批量交互，本版不做；继续评估 0.9 / 1.0。

5. **桌面**：仍是手机优先单栏，不做独立桌面工作台。
