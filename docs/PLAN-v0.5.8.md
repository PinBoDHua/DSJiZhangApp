# 薪时 v0.5.8 · 批量模板版

> 版本：0.5.8 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版补三块：批量扣款、逐天微调、常用批量模板。

---

## 1. 批量扣款

批量补记新增「扣款 / 天」：

- 默认 0；
- 不能为负；
- 与奖金、工时一起统一写入每一天；
- 逐天微调可以覆盖单日扣款。

## 2. 逐天微调

批量弹层新增可展开的「逐天微调」：

- 列出当前已选的全部日期；
- 每天可单独改工时、奖金、扣款；
- 留空表示继承顶部的批量默认值；
- 只有已勾选日期才会生成；
- 范围外勾选日期也可以逐天微调；
- 单日值非法时禁用生成并提示。

## 3. 常用批量模板

- 可将当前「工时 / 奖金 / 扣款 / 备注」保存为模板；
- 模板保存在本地 `xinshi.batchTemplates`；
- 下次打开批量弹层可直接套用；
- 同名模板覆盖，最多保留 8 个；
- 模板不包含日期范围和逐天微调；
- 支持删除。

## 4. 数据

- 不改变 schema，仍是 v7；
- 模板属于 UI 偏好，不进账本导出；
- 批量生成的工记字段与单笔表单一致；
- 备注留空回退「排班补记」。

## 5. 验收

### 单元测试：62 / 62

新增 3 个模板测试 + 2 个生成测试：

- 过滤无效工时、金额归一化；
- 同名模板覆盖，最多 8 个；
- 保存 / 读取 / 删除模板；
- 扣款写入；
- 逐天工时覆盖后时薪岗位不拆分时间。

### 浏览器自动化：63 个场景

新增 2：

- 批量 7h / 奖 20 / 扣 5，单日 11/10 改为 9h / 奖 30 / 扣 1，生成正确；
- 保存模板「夜班补记」，关闭重开后可再次套用。

### 其他

- 320 / 360 / 390 / 430px 无横向溢出；
- 控制台错误 0；
- APK 重新打包并在雷电 LDPlayer 14 验证。

## 6. 已知限制

- 逐天微调不支持单独备注；
- 模板只保存基础工时 / 奖金 / 扣款 / 备注，不保存日期范围和逐天覆盖；
- 模板是全局的，不区分岗位；
- 模板最多 8 个，同名覆盖；
- 计件、同天超过 24h、已结算日期会跳过。
