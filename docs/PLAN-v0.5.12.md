# 薪时 v0.5.12 · 月度考勤版

> 版本：0.5.12 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版把「这个月哪天上班、哪天休息」从单岗位月结月历，扩展成一张
> **多岗位 × 日期的月度考勤总表**；格子可以直接补记工、标整天 / 半天休息，
> 月结页也能从同一个月历里补记工记。

---

## 1. 问题

v0.5.10 的月结月历只解决了「当前岗位、当前周期」的休息补标：

- 想同时看几份工作这个月分别上了几天、休了几天，只能来回切岗位；
- 半天休只能按整天记，月休额度和超休扣款会算多；
- 月结时发现漏记工，只能退出结算去记录页补，再回来；
- 月结页点空白日期会直接标休息，没有「补记工」入口。

---

## 2. 方案

### 2.1 月度考勤总表

入口：记录页顶部「考勤」。

- 表头是岗位，行是日期；格子显示「班 Xh / 休 / 未记」；
- 顶部汇总：本月出勤天数、休息天数、工时；
- 每个岗位一行小计：`X 班 · Y 休 · Zh`；
- 已结算格子显示小锁，点开只读；
- 手机窄屏可以横向滑动看更多岗位；
- 支持上月 / 下月切换，「本月」一键回到当前月。

### 2.2 日期操作弹层

点任意格子打开当天该岗位的操作弹层：

- **补记工**：打开预填岗位和日期的记工页，保存后自动回到考勤；
- **标为休息**：可选「整天 / 半天（0.5 天）」，可填休息备注；
- **取消休息**：已有休息时可直接取消，支持撤销；
- **查看 / 编辑工记**：已有工记时打开详情；
- 已结算的日期只显示锁定提示，不提供修改入口。

### 2.3 月结页补记工记

月结页的「本月出勤 / 休息」月历不再直接标休息，而是打开同一个日期操作弹层：

- 点空白日期 → 补记工 / 标休息；
- 点休息日期 → 取消休息 / 补记工；
- 点已记工日期 → 查看工记；
- 补记或取消后，结算金额、出勤天数、休息天数立即重算；
- 新增工记会走和记录页一样的入口，保存后回到结算页，不丢失额外奖扣输入。

### 2.4 半天休

- `RestDay.days`：`0.5` = 半天，`1` = 整天，缺省按整天；
- 休息弹层、考勤弹层都能选整天 / 半天；
- 月休额度、剩余额度、超休天数、超休扣款、结算单、工资条、首页 / 统计 / 记录页的「休 X 天」全部按 0.5 累加；
- 半天只支持 `0.5`，不支持 0.25 或小时级请假。

---

## 3. 规则与边界

- 同一岗位同一天只能有一条休息记录；已有工记时不能标休息，反之新增工记会自动移除同日休息。
- 月度考勤的「出勤天数」按日期去重；岗位小计按「岗位 × 日期」计。
- 已结算周期不能补记 / 改休息；需要先撤销结算。
- 考勤表不生成排班，也不自动判断周末 / 法定节假日；只显示事实记录。
- 半天休照常参与固定额度与超休扣款；按出勤折算的月薪仍是不计薪的统计。
- 不新增存储键，仍是 v7；旧 `RestDay` 没有 `days` 时自动按 1 天。

## 5. 已知限制

- 考勤总表一次显示当前筛选的岗位；岗位很多时需要横向滑动。
- 只能按 0.5 天记半天，不支持按小时请假。
- 不支持整月批量补记 / 批量改状态；仍用单格操作。
- 已结算周期只读，改数据必须先撤销结算。
- 月度考勤不替代排班表，不自动识别节假日。
