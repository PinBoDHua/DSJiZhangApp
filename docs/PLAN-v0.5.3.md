# 薪时 v0.5.3 · 计划版

> 版本：0.5.3 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 这版不新增数据字段，把 v0.5.2 的固定周排班「显示出来」：首页未来 7 天、日历计划上班标记、排休冲突逐日清单。

---

## 1. 首页未来 7 天

如果岗位设置了固定上班日：

- 首页增加「接下来 7 天」卡片；
- 每天显示：上班 / 休息 / 已记；
- 今天有工记时显示已记；
- 今天计划上班但没记，标题显示「今天计划上班」，提示补记；
- 今天计划休息，标题显示「今天安排休息」；
- 只做提示，不自动生成工记。

## 2. 日历计划标记

- 日历在工作日显示「班」标记；
- 只标今天及以后、没有工记 / 休息 / 结算的日期；
- 选中计划上班日显示「按固定周排班，这天计划上班」；
- 选中计划休息日显示「按固定周排班，这天计划休息」；
- 实际工记和休息优先于计划，不重复标记。

## 3. 冲突逐日清单

排休计划在汇总提示下增加可展开清单：

- 已有工记：日期 + 「已有工记，不能排休」；
- 已结算：日期 + 「已结算，不能排休」；
- 按模板应上班但被选为休息：日期 + 「按固定周排班应上班，已选为休息」。

汇总提示仍然保留，清单用于逐日核对。

## 4. 数据

- 不改变 schema，仍是 v7；
- 所有计划从 `Job.workWeekdays + Entry + RestDay + Settlement` 派生，不新增冗余数据；
- 旧账本无需迁移。

## 5. 验收

### 单元测试：52 / 52

新增 `plan.test.ts` 4 个：

- 周一至周六 / 周日识别；
- 工记、休息优先于模板；
- 只列出没有工记 / 休息的计划上班日；
- 不固定岗位不产生计划。

### 浏览器自动化：53 个场景

新增 3：

- 首页未来 7 天；
- 日历「班」标记与计划上班 / 休息提示；
- 排休冲突逐日清单。

### 其他

- 320 / 360 / 390 / 430px 无横向溢出；
- 控制台错误 0；
- APK 重新打包并在雷电 LDPlayer 14 验证。

## 6. 已知限制

- 计划是派生展示，不会自动创建未来工记。
- 日历只标今天及以后，历史计划不补显示。
- 多个岗位不同排班时，首页只展示第一个有固定排班的岗位。
- 冲突清单只覆盖当前显示月份。
- 系统发薪通知仍是 Android 本地通知。
- 云同步需要服务端，仍放在 v0.6。
