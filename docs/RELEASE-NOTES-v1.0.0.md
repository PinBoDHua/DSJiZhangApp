# 薪时 v1.0.0 发布说明

> 版本：**1.0.0** ｜ versionCode：**1000** ｜ 发布日期：**2026-11-06**
>
> 主题：**留得住 · 看得见**
>
> 一句话：给工记留一张带水印的现场照片，文字版 PDF 可附多页工记明细，
> 回收站可按工作筛选；同时把 0.9 遗留的数据边界、导入与恢复规则一次收口。
> 数据格式冻结在 **schema v7**，旧备份继续可导入。

---

## 1. 本次更新亮点

### 1.1 考勤照片（离线水印）

- 记一笔时可拍照或从相册选择，自动压缩到长边 1280、单张 ≤ 600KB。
- 自动加「薪时 · 考勤留痕」水印，包含岗位名、日期、星期、在岗工时和拍摄时间。
- 照片只存本机 IndexedDB，不上传、不申请相机权限、不读取相册其他内容。
- 工记详情可看大图，也可保存到 `Download/Xinshi/`。
- 彻底删除工记 / 工作、清空回收站或清空所有数据时，照片一并清理。

### 1.2 文字版 PDF 多页

- 文字版工资条在结算摘要后附「工记明细」，按日期列出工时与本笔金额。
- 每页 36 行，长周期自动分页；续页带表头与页码。
- 休息日期 / 备注过长时自动换页，不再越过 A4 底边。
- 工资条设置新增「工记明细」开关；图片版 PDF 仍为单页。

### 1.3 回收站按工作筛选

- 类型（全部 / 工记 / 休息 / 借支 / 工作）+ 工作（全部工作 / 具体工作）组合筛选。
- 汇总金额 / 工时 / 休息天数跟随筛选结果，不再显示全量数字。
- 切换类型后当前工作无记录会自动回到「全部工作」；只有 2 份以上工作时才显示工作筛选。

### 1.4 数据边界收口

- 同一天多份工作合计超过 24 小时，在数据层直接拒绝，不再只靠界面提示。
- 同一工作周期重叠的结算会被拒绝；结算页给出「这个周期已经结算过了」。
- 记工覆盖同日休息时，休息移入回收站而不是静默删除。
- 恢复工记时若同日已有休息，提示先取消休息；恢复休息时若已有工记，同样拦截。
- 导入备份：坏回收站工作跳过、重叠结算拒绝、孤儿结算锁定在主动导入时解锁（本机读取保留给账本体检）。

### 1.5 版本与构建

- 关于页 / 引导页 / 页脚统一显示 **v1.0.0**，版本号仍只从 `package.json` 注入。
- Android `versionCode 1000` / `versionName 1.0.0`；Service Worker 缓存升级到 **v24**。
- 权限不变：仍只有通知、开机恢复提醒、WakeLock，**不申请 INTERNET / CAMERA**。

## 3. 升级与兼容

- **覆盖升级**：同签名可直接从 v0.9.0 覆盖安装，账本数据保留。
- **数据格式**：仍是 `xinshi.state.v7`，新增 `Entry.photoId` 为可选字段；旧备份缺省为空。
- **照片不迁移**：照片只存本机 IndexedDB，不写入备份 / 搬家包 / 本机快照；换设备或清空数据后需重新拍照 / 选图。
- **新备份在旧版本**：v0.9.0 打开 v1.0.0 导出的备份时会忽略 `photoId`，主账本仍可导入。
- **建议**：升级前在「我的 → 数据与安全」导出一次备份。

## 7. 已知限制

- **照片只在本机**：不随备份 / 搬家包 / 本机快照迁移；换设备或清空数据后需重新拍照 / 选图。
- **照片体积**：单张压缩到 600KB 内，长边 1280；极端大图会降质，仍超限需换一张。
- **相机调用**：通过系统相机 / 文件选择器完成，不申请 CAMERA；极少数 ROM 的文件选择器可能不弹出相机，请从相册选择。
- **回收站**：可按类型 + 工作筛选，暂不分页；恢复仍受原工作、结算周期、24 小时和休息冲突限制。
- **PDF**：图片版仍是单页；文字版多页明细不替代正式工资凭证。
- **未重跑 v1.0.0 真机**：原生壳与 v0.9.0 一致；本版完成构建、权限、浏览器场景、分辨率与深色验证。
- **计薪规则未变**：本版不调整任何工资算法，历史金额不受影响。
- 计薪结果仅供参考，不构成劳动、税务或法律意见。
