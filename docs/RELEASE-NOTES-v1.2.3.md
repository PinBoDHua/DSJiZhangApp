# 薪时 v1.2.3 审计修复与打磨说明

>

## 1. 本版定位

v1.2.2 已发布且出过签名包，因此本次审计修复按补丁版 **1.2.3** 发布：

- 不加新页面、不改数据格式、不做迁移；
- 只修「会丢记录 / 会算错钱 / 会导不出 / 会静默丢输入 / 会看不清 / 会没反馈」的问题；
- 修复后重新跑了单测、生产构建、15 视口响应式矩阵与浏览器亮 / 暗全链路验收。

## 2. 逻辑与数据修复

### 2.1 持久化与多窗口

- **跨标签页账本同步**：监听 `storage` 事件，其他窗口写账本时本机重载最新数据并提示，
  不再两个窗口各持旧账整包互相覆盖、后写者静默丢掉先写者的记录。
- **删除照片先落盘**：彻底删除 / 清空回收站时，先确认新账本已写入本地存储再删照片；
  落盘失败则保留照片，避免重启后「记录还在、照片没了」。
- **每日快照失败可重试**：快照保存失败时回退当日标记，不再直到重启前都漏拍每日快照。

### 2.2 备份与搬家

- **搬家包解密错误归因**：密码正确但账本结构损坏时原样上抛结构错误，不再误报
  「密码错误，或搬家包已损坏」让用户反复试密码（与 v1.2.2 普通备份同口径，补齐搬家包这条路径）。

### 2.3 离线缓存

- **Service Worker 缓存守卫**：导航与静态资源只缓存 `ok` 且非重定向的响应，5xx / 404 /
  门户重定向页不再污染离线兜底；后台更新用 `waitUntil` 兜底；activate 保留上一版缓存，
  配合 `vite:preloadError` 自动刷新（30 秒内不重复），新版部署后旧页面懒加载不再 404 落错误页。
  缓存版本升至 **v29**。

### 2.4 原生导出

- **Android 5–9 导出回退**：旧系统没有分区存储 Downloads API，原生插件改走 FileProvider
  系统分享面板保存 / 转发，备份、加密导出、工资条、Excel / CSV 不再在这些设备上一律失败；
  新增 `shared` 保存结果，前端文案零改动兼容。

### 2.5 计薪与对账

- **近 7 天图按窗口过滤**：`dailySeries` 先按区间过滤工记，窗口外的同月月薪记录不再参与
  分摊而稀释窗口内每日金额（整月出勤超 `expectedDays` 触发封顶时尤为明显）。
- **金额舍入精度**：`round2` 改指数记法移位舍入，修复 `8.165 → 8.16` 这类差 1 分的问题
  （`+EPSILON` 对部分值失效）；负值与超大 / 极小值口径保持不变。
- **Excel 月度汇总口径**：已结算周期内的休息日不再重复计入未结行；孤儿 `settlementId`
  （结算已删）的工记明细与汇总统一按「未结算」处理，导出内部不再自相矛盾。

## 3. UI/UX 修复（沿现有视觉）

- **记一笔脏检查**：日期 / 常用时长 / 休息 / 节假日开关等按钮改动与「管理」入口纳入脏标记，
  关闭或跳管理时未保存内容先弹「放弃这次编辑?」，不再静默丢输入；计时结束带出的工记预置
  脏标记，直接关闭也会确认。
- **未来月份可见**：记录 / 考勤月视图在存在未来记录（批量补记 / 排休）时允许向后翻页，
  不再永远看不到跨月的未来工记。
- **防重入与防旧图**：快照恢复 / 删除加防重入守卫；工资条选项变更重绘期间禁用保存 / 分享，
  不再导出旧版图片；搬家导入进行中禁止关闭抽屉，避免「以为取消了却仍覆盖」。
- **导出防连点**：导出备份 / 考勤 CSV / 工资流水 CSV 加 busy 态与加载文案，连点不再重复写文件。
- **多笔工记可达**：考勤日抽屉一天多笔工记时逐笔列出，不再只有第一笔可打开。
- **焦点与读屏**：焦点丢失到 body 时由最上层弹层收回，防止 Tab 逃逸到背景页；Toast 的
  `aria-live` 区域常驻（随内容挂载时读屏可能不播报）；图表柱加 `role="img"` 暴露数据。
- **暗色冷启动**：启动脚本同步 `meta theme-color`，暗色用户冷启动状态栏不再闪浅色。
- **iOS 剪贴板降级**：降级路径用 `readonly + setSelectionRange` 并恢复焦点，修复 iOS Safari
  复制不生效与焦点丢失。
- **错误逃生口**：根级 ErrorBoundary 增加「导出账本数据」，渲染崩溃源于数据损坏时不再只能
  无限刷新，可先留底原始数据。
