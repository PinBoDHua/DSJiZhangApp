# 薪时 v0.5.11 · 提醒修复版

> 版本：0.5.11 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 来自反馈：**每日记工提醒不生效，雷电模拟器和自己的手机都不响。**
> 这版把每日提醒从「网页通知」改成 Android 系统本地通知，App 关着也能按时间提醒。

---

## 1. 问题复现

APK 里打开「我的 → 提醒」：

- 每日记工提醒开关是开的，时间是 21:00；
- 下方却显示「浏览器通知 · 浏览器不支持」；
- 点「测试通知」没有反应；
- 等不到任何提醒。

根因有两层：

1. **每日提醒只用了 Web Notification API**：`useReminder` 和 `showLocalNotification` 走的是 `window.Notification` 和 Service Worker。Android WebView 不实现这套 API，所以 APK 里永远显示「浏览器不支持」，也不会有系统通知。
2. **发薪提醒已经用了 Capacitor 本地通知，但每日提醒没有接**：项目里已有 `@capacitor/local-notifications`，但只有 `schedulePaydayNotifications` 使用；每日提醒没有权限申请、没有通知通道、没有原生调度。

### 接入时踩的坑

第一版原生实现里，帮助函数直接 `return LocalNotifications`。Capacitor 的插件代理是可 thenable 对象，`async` 函数返回它时会被 Promise 当成 thenable 解包，报：

```
"LocalNotifications.then()" is not implemented on android
```

结果权限检查和调度全部静默失败。现在改为返回 `{ plugin: LocalNotifications }`，并补了计划生成的单元测试。

---

## 2. 方案

### 2.1 原生每日提醒

- 使用 `@capacitor/local-notifications`，通道 `xinshi-daily`，名称「每日记工提醒」。
- 一次排未来 **30 天**，每天在设定时间发一条本地通知。
- 当天已记工，或当天提醒时间已过，就从明天开始。
- App 启动、提醒时间变化、当天记工数变化时，重新排程；关闭开关时取消全部每日提醒。
- 通知 ID 使用 `8101–8130`，不与发薪提醒的 `7100+` 冲突。
- 调度前先取消旧 ID，避免重复通知。
- 不主动请求权限；权限由用户在「我的」里点开关 / 开启通知时申请。

### 2.2 提醒设置界面

- 原生端显示「系统通知 · 已开启 / 未开启 / 被拒绝」。
- 打开开关时申请系统通知权限；拒绝后提示去「系统设置 → 应用 → 薪时 → 通知」。
- 「开启通知」按钮：申请权限并立即排程。
- 「测试通知」按钮：原生端发一条 1.5 秒后的本地通知，用来验证通道和权限。
- 文案明确：`由系统通知提醒，App 关着也生效；当天已记工会跳过`。
- 网页端保留原逻辑：浏览器通知只在 App 打开时生效，并继续提供 `.ics` 日历提醒。

### 2.3 保持发薪提醒不变

发薪提醒原本就走原生本地通知，继续使用 `xinshi-payday` 通道和 `7100+` ID；这版只把每日提醒补齐，不改发薪规则。

## 3. 规则与边界

- 原生提醒计划是「未来 30 天」，不是永久重复；App 每次打开会续排。超过 30 天没打开 App，提醒会停。
- Android 12+ 没有申请精确闹钟权限，系统可能把提醒放在一个时间窗口内（省电 / Doze 下可能延迟）。
- 通知只是提醒，不会自动补工记；当天已记工则跳过当天那条。
- 网页端仍受浏览器限制：需要 HTTPS、通知权限，且只在页面打开时检查。
- 修改提醒时间会重排；关闭开关会取消每日提醒。
- 不新增存储字段，仍使用 `settings.reminder`，schema 仍是 v7。

## 4. 验收

### 单元测试：69 / 69

新增 1 个用例：

- 原生每日提醒排未来 30 天；当天已记工或时间已过时从明天开始；非法时间返回空计划。

### 浏览器自动化

- 原 68 个场景全部通过，包含 v0.2 的「提醒设置与日历文件」回归。
- Web 端提醒逻辑未改坏。

### Android 实机 / 模拟器

- 重新打包 `versionCode 511 / versionName 0.5.11`，安装到雷电 LDPlayer 14（Android 14）。
- 提醒设置页显示「系统通知 · 已开启」，测试通知实际出现在系统通知栏。
- `dumpsys alarm` 能看到 29 条 `TimedNotificationPublisher` 闹钟，时间均为 21:00，从次日起排。
- 关闭再打开 App 后会自动续排；当天已记工，所以当天不排。

---

## 5. 已知限制

- 30 天排程窗口；长期不打开 App 会停止续排。
- 未接入精确闹钟特殊权限，省电模式下可能延迟。
- 网页端仍不能做到 App 关闭后提醒；需要系统日历 `.ics` 或安装 APK。
- 通知权限被永久拒绝后，只能去系统设置手动打开。
- 不支持多个提醒时间、按星期几提醒、通知点击后直接跳到记工页（后续可做）。
