# 薪时 v0.5.9 · 模板互通版

> 版本：0.5.9 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版补三块：逐天备注、模板按岗位区分、模板 JSON 导入导出。

---

## 1. 逐天备注

「逐天微调」里每天新增备注输入：

- 留空继承统一备注；
- 填写后覆盖这一天的备注；
- 最多 40 字；
- 工时 / 奖金 / 扣款 / 备注可以同一天一起微调；
- 只有已勾选日期才生成。

## 2. 模板按岗位区分

- 保存模板时记录 `jobId` 和 `jobName`；
- 批量弹层只显示当前岗位模板；
- 旧版没有岗位信息的模板仍作为通用模板显示；
- 同名模板在不同岗位互不覆盖；
- 岗位改名后，导入的模板会按 `jobName` 兜底匹配。

## 3. 模板导入 / 导出

- 「导出模板」生成 `薪时批量模板-YYYY-MM-DD.json`；
- Android 写入下载目录，网页触发浏览器下载；
- 「导入模板」选择 JSON 文件；
- 文件格式：`app: xinshi` / `kind: batch-templates` / `version: 1` / `templates`；
- 导入后按「岗位 + 名称」合并，同名覆盖；
- 仍然最多保留 8 个；
- 非法 JSON、错误 kind、版本过高会报错，不会污染现有模板。

## 4. 数据

- 不改变 schema，仍是 v7；
- 模板存在本地 `xinshi.batchTemplates`，不进账本导出；
- 模板导入导出只处理模板文件，不动工记 / 结算；
- 逐天备注写入对应工记的 `note`。

## 6. 已知限制

- 模板不包含日期范围和逐天微调；
- 模板导入按名称合并，同名会被替换；
- 模板最多 8 个；
- 文件导入只接受薪时模板 JSON，不支持 CSV；
- 逐天备注最多 40 字，不支持富文本；
- 计件、同天超过 24h、已结算日期会跳过。
