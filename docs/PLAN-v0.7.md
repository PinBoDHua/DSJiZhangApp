### 竞品共同验证过的需求

1. **记录要快**：3–5 秒完成一笔，不要为了一个数字翻三页。
2. **日历要一眼看懂**：哪天干了、赚了多少、休没休。
3. **工资要能对账**：Excel / 工资条 / 结算单。
4. **数据要能带走**：备份、换机、导出。
5. **不要广告、不要强制登录**。

### 我们不做的事

- 不做社区 / 工厂点评 / 招聘（安心记加班的路线，不是我们的）。
- 不做账号与云同步（0.6.0 已明确暂停）。
- 不追「功能数量」；0.7.0 只做体验、速度、体积、审美。
- 不引入广告、统计 SDK、社交分享。

## 2. 0.7.0 的四个判断

### 2.1 轻：打开就能用

- 首屏只保留「本月到手 + 今天 + 最近」三层信息，其余折叠。
- 首页直接给「照上次记」「记上」「休息」「计时」四个高频动作。
- 记一笔默认带出最近岗位、班次、日期；常用时长一键选。
- 路由懒加载：首页、记一笔先加载；结算、考勤、体检、导出后置。

### 2.2 小：能少 1MB 就少 1MB

- Android release 开启 R8 + 资源压缩，去掉不用的 Java / 资源。
- 把未使用的 `html2canvas` 从打包链里剔除（文字 PDF / Canvas 工资条不需要它）。
- 页面按路由拆包，首屏 JS 目标降低 30% 以上。
- 字体保持 GB2312 覆盖，不为体积牺牲生僻字（留作后续评估）。
- 目标：**APK ≤ 4.5MB**，首屏主包（gzip）≤ 130KB。

### 2.3 美：像一件日用品，而不是一个后台系统

- 视觉层级：大数字、少边框、多留白；重要操作只有一个主按钮。
- 品牌：深松绿 + 暖纸色 + 琥珀点；新增柔和渐变与细颗粒感。
- 首页：本月卡片带「月进度」细条；今天卡片更轻；底部导航变成悬浮胶囊。
- 记一笔：底部抽屉更高、更安静；时间 / 工时 / 计件切换更清楚；底部实时工资预览。
- 统计：新增 12 周工时热力图，「辛苦看得见」。
- 动效：页面淡入、卡片按压、抽屉回弹、数字变化；尊重 `prefers-reduced-motion`。
- 图标 / 启动屏：更干净的渐变表盘，去掉多余描边。

### 2.4 稳：不破坏 0.6.0 的能力

- 计薪、结算、备份、搬家、体检、Excel、隐私合规全部保留。
- schema 仍是 v7；0.6.0 的备份 / 搬家包继续可导入。
- 所有旧 E2E 场景必须继续通过。

## 4. 关键实现

### 4.1 路由懒加载

- 保持 `Home`、`EntryEditor`、`Onboarding`、`PrivacyGate` 首屏加载。
- `Records / Settlements / Stats / Profile / Jobs / JobEditor / SettlementPage / Attendance / DataSafety / Snapshots / Health / Privacy` 使用 `React.lazy`。
- `Suspense` fallback 使用轻量页面骨架，不阻塞底部导航。
- 验收：`dist/assets/index-*.js` 从 600KB 降到目标区间；页面切换无白屏。

### 4.2 体积

- `vite.config.ts` 将未使用的 `html2canvas` alias 到空模块；确认工资条 PNG / 文字 PDF 仍正常。
- Android release：`minifyEnabled true`、`shrinkResources true`、`proguard-android-optimize.txt`。
- 保留 `com.xinshi.app.**` 与 Capacitor 插件 keep 规则。
- 记录构建前后 APK / AAB / 首屏 JS 对比。

### 4.3 视觉

- 新增一层 `v0.7 轻小美` 样式（在既有 design tokens 之上覆盖），不重写全部旧 CSS，降低回归风险。
- 只改视觉与少量 JSX，不改计薪与结算逻辑。

### 4.4 首页「照上次」

- 取最近一条带上下班时间的工记，点击直接打开记一笔并带入岗位、日期、班次。
- 只出现在今天还没记工、且存在可复用记录时。
- 不复制奖金 / 扣款（与「复制到今天」一致）。

### 4.5 记一笔时长快选

- 小时工的时间区间模式下，提供 4 / 6 / 8 / 10 / 12 小时快选。
- 按「开始时间 + 时长 + 休息」自动算结束时间；跨零点允许。
- 仍可手动改时间；快选只是填充，不改变计薪。

### 4.6 统计热力图

- 最近 12 周 × 7 天，颜色按当日工时或收入分 5 档。
- 图例与总计：12 周工时 / 收入。
- 空数据不显示热力图，保持空状态。
