# 薪时 v0.5.13 · 对账增强版

> 版本：0.5.13 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版补对账最后三块：**结算单二维码、工资条明细行自定义、月度考勤 CSV**。
> 不接后端，二维码只分享结算摘要，金额仍以本机账本为准。

---

## 1. 结算单二维码

- 结算历史底部新增「二维码」按钮。
- 弹层显示二维码、工作名、周期、应发净额。
- 二维码内容是紧凑结算摘要：
  - 工作、周期；
  - 应发 / 已收 / 待收；
  - 结算日期、单号后 8 位。
- 支持「保存二维码」PNG 和「复制摘要」。
- 不包含完整工记、身份证、手机号等隐私信息。
- 二维码库使用 `qrcode-generator`，纯前端生成，不依赖网络。
- 中文按 UTF-8 编码，扫码后可直接阅读中文摘要。

### 为什么不做在线核验

没有后端就没有可信的「验真」服务。二维码只是把结算快照摘要变成可扫描的文本，
方便当面/微信转发对账；金额真伪仍以双方约定和本机账本为准。

---

## 2. 工资条明细行自定义

工资条弹层新增「自定义明细行」：

- 可单独显示 / 隐藏：加班工资、奖金补贴、扣款、超休扣款、借支抵扣、休息日期。
- 页脚备注最多 30 字，例如「已核对，现金结清」。
- 选择保存在本机 `xinshi.payslipOptions`，下次打开继续使用。
- 只影响工资条图片 / PDF，不改结算金额、结算单文字和 CSV。
- 基础工资行始终显示，避免工资条失去主金额。

---

## 3. 月度考勤 CSV

月度考勤页右上角新增「导出 CSV」：

- 行是日期，列是岗位，每格为 `班 6h` / `休 0.5` / `未记`；
- 最后一列为当日总工时；
- 末尾「合计」行给出每个岗位的 `X 班 / Y 休 / Zh` 和总工时；
- 文件带 UTF-8 BOM，Excel / WPS 打开中文不乱码；
- Android 写入 `Download/Xinshi/`，网页触发浏览器下载；
- 文件名：`薪时考勤-YYYY-MM.csv`。

---

## 4. 数据与兼容

- 不新增 schema 字段，仍是 v7。
- 二维码只读结算快照，不写数据。
- 工资条偏好只存本机 `localStorage`，不进入账本导出；换设备后回到默认全显示。
- CSV 为纯文本，不包含金额，适合发给工头 / 雇主核对出勤。

## 6. 已知限制

- 二维码只有摘要，没有在线验真；对方修改截图无法识别。
- 二维码不嵌 Logo，纠错级别 M；打印或截图过小可能扫不出。
- 工资条自定义只保存在本机，不参与备份 / 云同步。
- 考勤 CSV 只有出勤状态与工时，不含工资和借支。
- 二维码包含单号后 8 位，仍建议只发给对账对象。
