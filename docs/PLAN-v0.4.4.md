# 薪时 v0.4.4 · 效率版

> 版本：0.4.4 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 这版补三件事：借支删错了能撤回、结算奖扣返回前会提醒、长期工一键带入 3500 / 月休 5 / 6h + 午休 2h。

---

## 1. 借支删除撤销

- 结算页删除借支后，Toast 显示「借支已删除 · 撤销」；
- 点撤销恢复原借支（原 id / 日期 / 金额 / 备注 / createdAt）；
- 恢复前检查：
  - 原工作是否还存在；
  - 是否已经有 settlementId；
  - 借支日期所在周期是否已经结算；
- 周期已结算、工作已删除时拒绝恢复并提示。

## 2. 结算奖扣返回提醒

结算草稿页修改以下任一内容后：

- 额外奖金；
- 额外扣款；
- 结算备注。

点返回 / 按 Android 返回键会先问「放弃这次奖扣？」：

- 取消：继续编辑；
- 放弃：返回结算列表，输入丢弃；
- 输入后又清空，视为未修改，不打扰；
- 确认结算成功直接进入结算单，不弹提醒。

Android 返回键由结算草稿页接管；`App` 的页面级返回不再抢这个页面的返回。

## 3. 长期工一键模板

工作管理页顶部新增「长期工模板」卡片：

> 3500 元 · 月休 5 天 · 6h + 午休 2h

点一下打开预填好的新工作：

| 字段 | 预填 |
| --- | --- |
| 名称 | 长期工 |
| 计薪方式 | 月薪 |
| 单价 | 3500 |
| 结算周期 | 月结 |
| 月薪算法 | 固定月薪 |
| 月休额度 | 5 天 |
| 标准工时 | 6 小时 |
| 默认班次 | 09:00–17:00 |
| 午休 | 120 分钟 |
| 加班 | 关闭 |

名称、金额、班次仍可保存前修改；保存后就是普通工作，不绑定模板。
