## 2. 数据安全与账本一致性

- **跨标签页账本覆盖（P0）**：读取账本不再顺手整本回写 localStorage，避免「读-改-写」
  覆盖另一个窗口刚保存的新记录；跨窗口同步时本地有未落盘改动先不接收远端状态。
- **导入/恢复不再「假成功」**：`replaceState` 改为先同步落盘成功再切换内存状态，失败时
  明确提示「本机存储写入失败，操作未生效」；持久化失败时首页常驻告警条。
- **导入字段上限**：手改或第三方备份里的工时 / 计件 / 奖金 / 扣款 / 午休按录入口径钳制
  （`hours ≤ 24`、`quantity ≤ 100 万`等），不会把 1000 小时记进账本。
- **休息日重复 ID**：导入时拒绝，避免取消一天休息连带删掉另一天。
- **安全快照**：导入 / 清空 / 恢复前的快照不再被「同内容的自动快照」顶掉；读取快照时
  校验内容 hash，被清理工具改坏的快照会明确报损坏。
- **回收站保留期**：超过 30 天的记录不能再恢复。
- **照片删除顺序**：先确认账本落盘成功再删照片，避免「记录还在、照片没了」。
- **Android 5–9 导出**：系统分享面板打开不等于已保存，不再误记「已备份」、不再重置
  14 天备份提醒。

## 3. 计薪 / 结算 / 统计口径

- **固定月薪 + 周结/日结待结金额**：改为按「岗位 × 结算周期」逐期折算汇总。此前
  2 天工记会按整自然月显示待结 ¥3500（实际本期应结 ¥318.18），首页 / 结算页 / 工作管理
  全部修正。
- **结算列表预览**：补上超休扣款与借支抵扣，列表「本期应结」与核对页 / 实际提交金额一致。
- **同日多段调价**：日薪的「唯一日薪基数」统一取当天 `createdAt` 最新快照，结算与统计
  不再一边取最早、一边取最新而差一笔钱（图表 / 日历同源）。
- **统计周档**：合计与柱状图改为同一汇总口径，不再差 1 分。
- **工资条**：文字版明细注明「逐笔折算参考，合计以应发净额为准」。
- **性能**：未结数据单遍分析 + 按账本身份缓存，首页不再重复计算 2–3 遍。

## 4. 页面与交互

- **提前结算警示**：本期未结束/未开始时确认框明确提示「剩余日期将无法再记工」。
- **改周期守卫**：改「一周从哪天开始」或岗位结算周期会与旧结算重叠时，保存前阻断并提示先撤销结算。
- **归档岗位**：结算页 / 考勤页补记入口改为只读提示，记一笔不再静默换成另一份工作。
- **待收可见**：区分「未结工钱」与「已结算待收」，不再一结算就显示「工钱已结清」。
- **跨月结算单**：按周期结束日归属月份，不再在两个月的流水里重复计入。
- **负净额结算**：二次确认后才落库。
- **加班上限**：日/月薪加班时长不能大于总工时，不再静默裁剪。
- **计时补记**：超过 24 小时的计时按 24 小时上限带出并提示拆分核对（正好 24 小时不再提示「不足 1 分钟」）。
- **切换计薪方式**：清空旧单价并提示重新填写，避免「月薪 25 元/月」。

## 5. 隐私、可访问性与平台

- **隐藏金额**：补齐柱状图当天柱顶金额、读屏文本、分享二维码、搬家包预览、快照合计、
  预算目标等漏点。
- **焦点/返回键**：修复受控抽屉焦点陷阱失效；Toast 撤销不再吞掉排队提示；金额输入框补
  可访问名称；安卓返回键在「数据与安全 → 子页」按层级回退，隐私政策子页不再直接最小化 App。
- **发布卫生**：`.gitignore` 补齐密钥/环境文件规则（已核实 keystore 与口令从未入库）；
  FileProvider 从「整个外部存储 + cache 根」收窄到 `cacheDir/exports/`；release 构建缺少
  签名配置时显式失败，不再静默产出 unsigned 包。
- **隐私政策**：默认地址改为构建产物自带的离线页 `privacy-policy.html`，不再指向已 404 的
  GitHub Pages 地址；上架前仍可用 `VITE_PRIVACY_URL` 覆盖为真实公开地址。
- **发布检查**：新增 `pnpm check:release`（版本号 / SW 缓存 / 隐私地址 / 敏感文件 / 签名守卫，
  当前 8 PASS）。
