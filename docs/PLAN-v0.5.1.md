# 薪时 v0.5.1 · 省心版

> 版本：0.5.1 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 这版补三件事：Android 系统级发薪通知、工作删除回收站、批量排休计划。

---

## 1. Android 系统级发薪通知

- 工作设置里的「发薪日」现在会调度 Android 本地通知；
- 默认在发薪日 **09:00** 提醒；
- 一次调度未来 3 个月，打开 App 会自动重排；
- 通知文案：`今天发薪 · 老宅装修 · 记得核对结算和登记收款`；
- 通知通道：`发薪提醒`；
- 删除 / 归档岗位或取消发薪日后，会清理旧通知；
- 网页端没有系统通知，只保留首页发薪横幅。

实现方式：`@capacitor/local-notifications`，不依赖服务器。

> 首次使用会请求通知权限；拒绝后不再反复弹窗，首页横幅仍然可用。

## 2. 工作删除回收站

- 没有工记、借支、结算的工作可以删除；
- 删除后不再直接消失，而是进入**工作回收站**；
- 工作管理页出现「回收站 N」入口；
- 可恢复，也可彻底删除；
- 删除时 Toast 仍可立即「撤销」；
- 有记录的工作仍然只能归档，归档可在工作管理里恢复。

回收站只保存空工作，避免工记引用不存在的工作。

## 3. 批量排休计划

- 休息弹层新增「批量排休 / 提前安排休息日」；
- 打开月历，选择未来休息日；
- 只允许选今天及以后、没有工记、未结算的日期；
- 显示本月已休 / 额度、已选天数；
- 保存后写入休息记录，进入日历休息标记和月休额度；
- 已有休息日会以咖啡杯标记，不能重复选择。

## 6. 已知限制

- 发薪通知是系统本地调度，不保证省电策略下毫秒级准时；默认 09:00，系统可能略有延迟。
- 通知权限被拒绝时只保留应用内横幅。
- 回收站只支持空工作；有记录的工作只能归档。
- 批量排休只增加休息日，不会自动删除已有休息日。
- 排休超过额度会继续写入，是否扣款由超休规则或结算时决定。
