# 薪时 v0.5.0 · 发薪版

> 版本：0.5.0 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 0.5.0 把「记工 → 算钱」继续接到「发钱」：超休扣款、收款状态、本月结算流水 CSV、发薪日提醒。
> 云同步仍需要服务器，列入 v0.6。

---

## 1. 超休扣款（可选）

固定月薪岗位新增两项规则：

- `overRestDeduct`：超过月休额度是否扣款，默认关闭；
- `overRestDailyRate`：每天扣多少，0 表示按月薪 ÷ 计薪天数自动计算。

结算时：

- 本月休息超过额度 → 显示「超休 X 天」；
- 默认扣款 = 超休天数 × 每天金额；
- 结算页可以单期关掉，或直接改本期扣款金额；
- 扣款上限为本期固定月薪，不会扣成负数；
- 结算单、金额明细、工资条、CSV 都保留「超休扣款」一项。

示例：3500 / 22 天，月休额度 5 天，实际休 6 天 → 超休 1 天，约扣 159.09。

> 这是个人对账工具，不替用户判断劳动法或公司制度；默认关闭。

## 2. 收款状态

结算单新增：

- 状态：待发 / 部分发放 / 已发；
- 已收总额、收款日期、方式、备注；
- 支持部分收款，剩余继续挂账；
- 可修改已收总额纠正错误；
- 结算历史显示状态，本月流水显示已收 / 待收。

收款只是记录，不接支付渠道。

## 3. 本月结算流水 CSV

结算页新增「本月结算流水」卡片：

- 本月应发；
- 本月已收；
- 本月待收；
- 导出 CSV（Android 保存到 `Download/Xinshi/`，网页直接下载）。

CSV 列包含：工作、周期、出勤、休息、工时、基础工资、加班、奖金、扣款、超休扣款、借支、应发、已收、待收、收款状态、日期、方式、备注。

## 4. 发薪日提醒

- 工作设置新增「发薪日」（1–31 号）；
- 首页在发薪日前 3 天 / 当天显示提醒；
- 点提醒进入结算页核对和登记收款。

目前是**应用内提醒**，不依赖服务器；系统级后台通知需要额外原生权限，放在 v0.5.1。

## 7. 已知限制

- 发薪日提醒仅应用内；没有系统后台通知。
- 超休规则只针对固定月薪，默认关闭，不与考勤制度自动对齐。
- 收款只记录已收总额，不拆分每笔到账流水。
- 本月流水只包含**已结算**的结算单；未结算工记在「待结算」里，不写入 CSV。
- 云同步需要服务端，继续暂缓。
