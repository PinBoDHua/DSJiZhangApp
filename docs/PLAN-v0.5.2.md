# 薪时 v0.5.2 · 排班版

> 版本：0.5.2 ｜ 日期：2026-11-04 ｜ 状态：已实现并通过验收
>
> 这版把「休息计划」再往前推：固定上班日模板、超额 / 冲突提示、回收站 30 天自动清理。

---

## 1. 固定周排班

工作设置新增「固定上班日」：

- 可选周一至周日任意组合；
- 预置「周一至周六」「不固定」；
- 只用于**批量排休**，不会自动记工；
- 长期工模板会默认带入「周一至周六」。

排休计划里出现模板后：

- 显示「固定上班：周一…周六」；
- 一键「按周排班选休息日」，自动选中当月未来的周日（或未上班日）；
- 已有工记、已休息、已结算的日期自动跳过。

## 2. 排休冲突 / 超额提示

排休计划里新增两类提示：

- 本月有 N 天已有工记或已结算，不能排休，自动跳过；
- 已休 + 已选超过月休额度 N 天，仍可保存，是否扣款由超休规则决定。

保存超过额度时会提示「已排 X 天休息，超过本月额度 N 天」。

## 3. 回收站 30 天自动清理

- 删除的空工作进入回收站；
- 回收站显示「还剩 X 天」；
- 超过 30 天在载入数据 / 导入备份时自动清理；
- 仍可手动恢复或彻底删除。

## 4. 数据 v7

- 存储键：`xinshi.state.v7`；
- 兼容 v1–v6；
- `Job.workWeekdays` 为可选数组，旧数据为空表示不固定；
- 回收站清理不改变剩余工作 / 工记 / 结算；
- 导出包 `version: 7`。

## 6. 已知限制

- 固定周排班只影响排休计划，不会自动创建未来的工记。
- 排休超过额度仍会写入，不做强制阻止。
- 回收站只保存空工作，自动清理周期固定 30 天，不可配置。
- 系统发薪通知仍是 Android 本地通知，不保证毫秒级准时。
- 云同步需要服务端，仍放在 v0.6。
