# 薪时 v0.5.7 · 批量编辑版

> 版本：0.5.7 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版把批量补记从“只能选预设范围”升级为“自定义起止 + 批量改工时/奖金 + 跨范围保留勾选”。

---

## 1. 自定义起止日期

批量补记支持：

- 未来 7 / 14 / 30 天快捷范围；
- 自定义「从 / 到」日期；
- 最小日期为今天，最大为今天 +365 天；
- 结束日期早于开始日期时自动对齐；
- 范围内只显示没有工记、休息、结算的计划上班日。

## 2. 跨范围保留勾选

- 切换 7 / 14 / 30 天或自定义日期时，手动勾选不丢失；
- 范围外的已选日期会显示具体日期和数量；
- 这些范围外日期仍会一并补记；
- 「清空」会清掉全部勾选；
- 「全选」只补齐当前范围，不清除范围外勾选。

## 3. 批量改工时 / 奖金

- 新增「工时 / 天」「奖金 / 天」；
- 默认工时按岗位班次净工时（固定月薪默认 6h）；
- 工时必须大于 0 且不超过 24h；
- 奖金按天写入，不能为负；
- 修改工时后，时薪岗位改用统一工时，不再拆分上下班时间；
- 备注仍支持统一填写。

## 4. 数据

- 不改变 schema，仍是 v7；
- 批量生成的工记字段与单笔表单一致；
- 固定月薪工时只影响统计，不影响整月工资；
- 备注留空回退「排班补记」。

## 6. 已知限制

- 自定义范围最大 365 天；
- 范围外勾选会一并生成，界面上用黄色提示列出日期；
- 批量奖金统一按天，不支持逐天不同金额；
- 批量扣款暂不支持；
- 计件、同天超过 24h、已结算日期会跳过；
- 批量补记只针对当前选中的一个岗位。
