# 薪时 v0.5.14 · 对账增强 II

> 版本：0.5.14 ｜ 日期：2026-11-05 ｜ 状态：已实现并通过验收
>
> 这版把 v0.5.13 的三块对账能力继续做深：
> **二维码加校验码、工资条模板、可选中 / 可搜索的文字版 PDF**。

---

## 1. 二维码校验码

- 结算二维码内容新增 `校验码：XXXX-XXXX`；
- 二维码弹层在金额下方显示同一个校验码；
- 复制结算单文字也会带上校验码；
- 校验码由结算快照的稳定字段计算：
  - 结算 ID、岗位 ID、岗位名；
  - 周期开始 / 结束；
  - 应发净额；
  - 结算创建时间。
- 使用 FNV-1a 32 位哈希，输出 8 位十六进制，格式 `XXXX-XXXX`；
- 同一张结算单稳定，金额或周期改动后会变化。

> 校验码不是数字签名，没有后端验真；它只用于双方核对「是不是同一张结算单」，
> 不能防止对方伪造截图。

---

## 2. 文字版 PDF

工资条弹层新增「文字版 PDF（可选中 / 可搜索）」：

- 使用 jsPDF + 内嵌 Noto Sans SC 子集生成 **真正的文字 PDF**；
- 文字可选中、可复制、可搜索，不再是图片 PDF；
- 内容包含：
  - 岗位、周期、应发净额；
  - 出勤 / 休息 / 工时；
  - 当前模板下的明细行；
  - 休息日期、备注；
  - 二维码、校验码、结算时间、页脚备注。
- 字体资源 `public/fonts/xinshi-sans.ttf` 约 2.4 MB，按需 `fetch`，不进入 JS 主包；
- 覆盖 ASCII、GB2312 汉字与常用中文标点；
- 字体使用 SIL OFL 1.1，来源 Noto Sans SC。

---

## 3. 工资条模板

工资条设置新增模板选择：

| 模板 | 行为 |
| --- | --- |
| 完整版 | 全部明细行、休息日期都显示 |
| 简洁版 | 隐藏超休扣款、借支抵扣 |
| 只发金额 | 隐藏超休 / 借支 / 休息日期，页脚写「仅金额对账」 |
| 自定义 | 手动勾选任意明细行 |

- 切换模板立即重生成工资条图片；
- 模板与勾选状态保存在本机 `xinshi.payslipOptions`；
- 只影响工资条图片 / 文字版 PDF，不改结算金额；
- 自定义后模板自动标记为「自定义」。

## 4. 数据与兼容

## 6. 已知限制

- 校验码不是签名，不能在线验真。
- 字体子集覆盖 GB2312 常用字；极少数生僻字可能显示不全。
- 文字版 PDF 目前单页 A4；超长备注会截断 / 换行。
- 模板是内置三套 + 自定义，不支持命名保存多个自定义模板。
- 字体资源在首次文字版 PDF 时加载，离线首次使用需要确保资源已缓存。
